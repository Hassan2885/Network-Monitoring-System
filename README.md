**Network Monitoring System**



**Introduction**



The Network Monitoring System is a C++ project developed to understand how servers are monitored and how their availability can be managed. It is a console-based program where users can check server status, change server conditions and view network reports.



&#x20;**Project Features**



The project includes the following features:



* 1\. View the status of all servers.
* 2\. Turn a server offline.
* 3\. Turn a server online.
* 4\. Check network availability.
* 5\. Perform an automatic failover check.
* 6\. View the network dashboard.
* 7\. Simulate application deployment.
* 8\. Check the overall system health.
* 9\. Generate a server recovery report.



**Technologies Used**



* \- C++
* \- Object-Oriented Programming (OOP)
* \- Dev-C++ IDE



&#x20;





**Note**



This project is a basic simulation of a network monitoring system. It demonstrates server status management, failover checks and deployment-related operations. It does not monitor real servers or perform actual Kubernetes deployment.
